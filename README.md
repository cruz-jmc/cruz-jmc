## Software Engineering Interests

Some of the areas I'm studying include:

**Software Architecture**
Understanding how applications are structured and how architectural decisions affect scalability, maintainability, and evolution.

**System Design**
Learning how to design software systems capable of solving real-world problems while considering their requirements and constraints.

**Design Patterns**
Studying reusable solutions to common software design problems and understanding when they should—or shouldn't—be applied.

**Requirements Engineering**
Understanding how to identify, analyze, document, and manage the requirements of a software system.

**UML & Documentation**
Using diagrams and documentation to communicate software structure, behavior, and design decisions.
